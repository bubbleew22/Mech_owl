# Snow Owl Android downloads

Version 1.2.0: signed Manager and Companion APKs.

- Manager: private shop records, master approvals, registered-device limits, installments and receipts.
- Companion: consenting customer-device enrollment, without a customer email/password interface.

Download an APK, confirm Android installation and review the requested permissions. SHA-256 hashes and signing certificate fingerprint are in release.json. Only APK binaries and public integrity metadata are published here.

Normal Device Admin mode supports a PIN-unlockable screen lock. Persistent payment-only restrictions require supported managed-device enrollment. Recovery/hardware-reset protection is not claimed.
